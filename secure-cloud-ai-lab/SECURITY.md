# Security Policy

This file will be completed before any public security challenge.

## Planned content

- Scope: which Azure resources are in scope for testing.
- Rules of engagement: no denial of service, no social engineering of people, no access to data outside the lab.
- How to report a finding (contact, expected response time).
- Safe harbor statement for good-faith research.

Until this is published, please do not test any system related to this project.
